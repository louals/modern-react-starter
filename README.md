# Modern Core Website Starter

A clean, production-ready web application template built with **React 19**, **TypeScript**, **Vite 6**, and **Tailwind CSS v4**.

## Features

- **React 19 & Vite 6**: Next-generation speed and developer experience.
- **Tailwind CSS v4**: CSS-first configuration using `@import "tailwindcss"`.
- **Theme Switcher**: Instant dark, light, and system-preference theme toggle via CSS variables.
- **WCAG 2.2 AA Accessibility**: Skip link, keyboard navigation focus rings, semantic landmark layout.
- **Wouter**: Blazing-fast router under 2KB.
- **Zero Vulnerabilities**: Clean dependencies, strictly typed, modern ESLint 9 configuration.

## Quick Start

```bash
# 1. Copy template to your new project folder
cp -r templates/modern-core my-new-app
cd my-new-app

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Production build & typecheck
npm run build
```
